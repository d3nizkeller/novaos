# Архитектура NovaOS

NovaOS — это два крейта и набор инструментов упаковки. Всё, что можно
проверить без телевизора, покрыто тестами: 95 в `nova-core`, 57 в
`nova-launcher`, плюс прогон кадров в CI.

```
┌────────────────────────────── nova-launcher ──────────────────────────────┐
│  main.rs → backend/{sdl,offscreen} → screens → widgets → gfx (Canvas RGBA) │
│                                     ↕                                      │
│                              state (AppState)                              │
│                                     ↕  Command / Event (mpsc)              │
├────────────────────────────── nova-core ──────────────────────────────────┤
│  ipk · apk · axml · arsc · sniff · install · luna · repo · upload · home   │
│  catalog · settings · sysinfo · clock · qr · png · net · i18n              │
└────────────────────────────────────────────────────────────────────────────┘
```

## Цикл кадра

Бэкенд (`backend/sdl.rs` или `backend/offscreen.rs`) крутит один и тот же цикл:

1. события пульта → `screens::Key` → `screens::handle_key`;
2. `AppState::tick(dt)` — часы, анимация фокуса, тосты, заставка, приём событий
   от фонового потока;
3. `screens::layout(state)` — прямоугольники элементов из данных состояния;
4. `screens::draw(state, ctx, layout)` — кадр в RGBA-холст 1920×1080;
5. холст уходит в потоковую текстуру SDL2 (`ABGR8888`) или в PNG.

Раскладка и ввод пользуются одними функциями окон прокрутки
(`screens::window_for`), поэтому фокус не может оказаться на элементе, который
не нарисован: секция хранит видимые прямоугольники, логическое число элементов
и смещение окна (`screens::Section`).

## Слои интерфейса

- `gfx` — холст RGBA: скруглённые заливки (SDF), тени, радиальное свечение,
  билинейный ресайз изображений, текст через `ab_glyph` с кэшем глифов,
  кодирование PNG без системных библиотек.
- `theme` — логическая сетка 1920×1080, четыре тёмные палитры (контраст текста
  к фону ≥ 7:1), типографика и метрики; `scale_for(width)` масштабирует сетку
  под 720p.
- `widgets` — плитки, карточки героя, строки списков, диалоги, тосты,
  экранная клавиатура, QR-блок, подсказки пульта. Виджеты не знают о состоянии:
  им передают данные и коэффициент фокуса.
- `screens` — раскладка (`layout`), модели представления (`AppView`,
  `StoreView`), отрисовка (`draw`), ввод (`handle_key`, `handle_modal_key`) и
  подсказки (`hints_for`). Модальные окна снимают «срез» данных
  (`ModalData`/`Kind`), чтобы не держать заимствования состояния во время
  мутабельных вызовов.
- `state` — `AppState`: экраны, фокус, модальные окна, прогресс, тосты,
  настройки; фоновый поток выполняет `Command` (сканирование каталога,
  синхронизация репозиториев, загрузка иконок, установка) и присылает `Event`.
  В инлайн-режиме (`AppState::inline`) команды выполняются синхронно — так
  тесты видят эффекты без `tick`.

## Установка пакетов

`nova_core::install` ведёт пакет по конвейеру:

```
источник (URL / файл / USB / загрузка с телефона)
   → sniff::detect (IPK, APK, ZIP, веб-папка)
   → загрузка + SHA-256
   → приведение к IPK (webapp/APK-обёртки)
   → ipk::parse (control, appinfo, размер)
   → стратегия: AppInstallService | HomebrewUrl | HomebrewExec | ManualExtract
```

Стратегия выбирается по возможностям устройства (`sysinfo`): сервис
`com.webos.appInstallService/dev/install` без root, сервис Homebrew Channel
`org.webosbrew.hbchannel.service/install` с root, а при их отсутствии —
пошаговая инструкция `ManualExtract` с командой для SSH
(`nova --extract-ipk`).

Приёмник файлов с телефона (`nova_core::upload`) поднимает HTTP-сервер в
локальной сети и показывает QR-код с адресом; принятый файл сразу уходит в
конвейер установки и открывает диалог подтверждения.

## Подмена штатного Home

`nova_core::home` строит план (`HomePlan`) по версии webOS:

- webOS 3–4 (включая UM7300PLB): копия каталога `com.webos.app.home` в
  `/var/lib/novaos-home/app`, точка входа в её `appinfo.json` переписывается на
  `nova`, каталог монтируется поверх штатного (`mount --bind`);
- webOS 5+: bind-mount бинарника `nova` поверх файла `main` LG Home;
- режим «Автозапуск» ничего не подменяет, а ставит хук
  `/var/lib/webosbrew/init.d/50-novaos-home`, который запускает NovaOS после
  загрузки.

Скрипты (`home.sh`, хук, откат) генерируются кодом и лежат в `tv/` — пример
`tvfiles` держит их синхронными с реализацией.

## Часы, календарь, шрифты

`nova_core::clock` считает гражданскую дату по алгоритму Хиннанта, форматирует
время по-русски («21:40», «9:40 вечера») и дату («суббота, 31 октября»),
разбирает TZif v1–v3 и POSIX-TZ, берёт смещение из `NOVA_TZ_OFFSET`, `TZ` или
`/etc/localtime`.

Шрифты — подмножества Inter (52 КБ на начертание, ~530 глифов: кириллица,
латиница, цифры, стрелки и служебные символы пульта). Подмножество собрано
`fontTools.subset` с `--desubroutinize` и лежит в `assets/fonts/`.

## Тестирование

- `nova-core`: разбор настоящих пакетов (IPK webosbrew), AR/TAR/GZ, AXML/ARSC
  APK, Luna-запросы на мок-шине, конвейер установки в dry-run, home-планы для
  разных webOS, часы и TZif.
- `nova-launcher`: раскладка умещается в экран на всех страницах, прокрутка
  держит фокус видимым, навигация и цветные кнопки, клавиатура, настройки,
  магазин, отрисовка каждого экрана и модальных окон без паник, бэкенд
  offscreen со сценарием нажатий.
- CI дополнительно рендерит кадры и прогоняет упаковку IPK «всухую».
