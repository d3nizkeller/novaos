# Установка NovaOS на телевизор

Инструкция проверена на LG webOS TV UM7300PLB (webOS 4.x) и подходит для
моделей webOS 3–6 с поправками на способ рутирования.

## 1. Подготовка телевизора

1. Включите режим разработчика: приложение **Developer Mode** из LG Content
   Store либо `rootmy.tv` / [webosbrew.org/rooting](https://www.webosbrew.org/rooting/)
   для постоянного root.
2. Для постоянного root установите **Homebrew Channel** — он даёт сервис
   `org.webosbrew.hbchannel.service` с правами root и менеджер пакетов.
3. Узнайте версию webOS: **Настройки LG → Общие → Информация о телевизоре**.
   NovaOS покажет её сам на экране «О системе» вместе с вердиктом
   совместимости.

## 2. Установка пакета

### Через магазин NovaOS или Homebrew Channel

Соберите репозиторий (или возьмите готовый из релизов):

```bash
tools/build-webos.sh            # dist/com.novaos.launcher_0.1.0_arm.ipk + repo.json
```

Разложите `dist/` на любой HTTPS-хостинг (GitHub Pages подойдёт — рабочий
поток `release.yml` делает это сам) и в NovaOS откройте
**Настройки → Добавить репозиторий**, указав адрес `repo.json`. Пакеты
появятся в магазине с проверкой SHA-256 и размера.

До установки NovaOS (когда лаунчера ещё нет) ставьте через Homebrew Channel:
**Add repository** → тот же `repo.json`, либо вручную из SSH-терминала:

```sh
luna-send -n 1 luna://org.webosbrew.hbchannel.service/install \
  '{"ipkUrl":"https://…/com.novaos.launcher_0.1.0_arm.ipk","ipkHash":"<sha256>","subscribe":false}'
```

### С флешки или по сети без репозитория

- Скопируйте IPK на USB-накопитель: на экране **Установка** выберите
  «Сканировать USB», затем строку с пакетом.
- Включите **Приём файлов с телефона** и отсканируйте QR-код: страница
  загрузки примет файл из локальной сети и сама откроет диалог установки.
- Укажите прямую ссылку: **Установка → Установить по ссылке**.

### Вручную, без root-сервисов

```bash
nova --extract-ipk com.novaos.launcher_0.1.0_arm.ipk --dest /tmp/nova
```

Команда распакует `data.tar.gz` и напечатает строку для SSH, которая
разложит файлы по `/media/cryptofs/apps` и зарегистрирует приложение.

## 3. Кнопка Home

**Настройки → Кнопка Home**:

- **Подменять Home** — NovaOS становится оболочкой по нажатию Home.
  На webOS 3–4 монтируется каталог-копия штатного Home с переписанной точкой
  входа, на webOS 5+ — bind-mount исполняемого файла.
- **Автозапуск** — Home не трогается; хук
  `/var/lib/webosbrew/init.d/50-novaos-home` запускает NovaOS после загрузки.
- **Выключено** — NovaOS работает как обычное приложение.

Состояние подмены живёт в `/var/lib/novaos-home`: там копия оригинального
Home, журналы и скрипт отката. Строка **Настройки → Кнопка Home → Выключено**
возвращает штатную оболочку без перезагрузки; если оболочка уже не отвечает,
выполните в SSH:

```sh
/var/lib/novaos-home/restore.sh
```

## 4. Обновление и удаление

- Обновление: магазин покажет «Обновить» у пакета с новой версией; установка
  идёт поверх, настройки и избранное сохраняются в `/var/lib/novaos`.
- Удаление: **Приложения → красная кнопка** на пакете или карточка пакета →
  «Удалить» (штатные приложения LG не удаляются и помечаются как системные).

## 5. Диагностика

Экран **О системе → Диагностика** показывает модель, версию webOS, архитектуру,
число приложений в каталоге, ошибки сканирования и вердикт совместимости.
Журнал подмены Home — `/var/lib/novaos-home/boot.log`.

### Если лаунчер не запускается

1. **Версия пакета ≥ 0.1.3.** Прошивка webOS не содержит SDL2, поэтому начиная
   с 0.1.2 пакет возит `libSDL2-2.0.so.0` в своём каталоге `lib/`, а бинарник
   собран с RPATH (пакеты 0.1.0/0.1.1 ставились, но не стартовали). Начиная с
   0.1.3 на телевизоре всегда включён оконный бэкенд SDL: раньше при отсутствии
   `DISPLAY`/`WAYLAND_DISPLAY` лаунчер молча уходил в режим без окна — процесс
   жив, изображения нет. Обновитесь из репозитория или релиза.
2. Проверьте раскладку пакета на устройстве:

   ```sh
   ls -la /media/cryptofs/apps/usr/palm/applications/com.novaos.launcher
   # обязаны быть: nova, appinfo.json, icon.png, lib/libSDL2-2.0.so.0
   ```

3. Запустите бинарник вручную из SSH — ошибки загрузчика видны сразу:

   ```sh
   cd /media/cryptofs/apps/usr/palm/applications/com.novaos.launcher
   ./nova --version          # загрузчик нашёл все библиотеки
   ./nova --smoke            # 45 кадров в /tmp/nova-smoke и NOVA_SMOKE_OK
   ```

   Если `--version` говорит «error while loading shared libraries» — в
   каталоге нет `lib/` или пакет старше 0.1.2.
4. Журнал лаунера `/tmp/nova-crash.log` (дубль `/var/lib/novaos/crash.log`)
   говорит, где оборвался запуск:
   - строки `start: NovaOS 0.1.3 … бэкенд sdl` нет — процесс не дошёл до
     `main` (проблема загрузчика библиотек, см. пункт 3);
   - есть `start:`, но экран чёрный — смотрите строку `sdl: …`: в ней причина
     отказа видеоподсистемы (сокет композитора, EGL);
   - есть `panic: …` — авария в коде лаунчера, строка содержит место.
5. Запуск через Luna вручную (ответ приходит прямо в терминал):

   ```sh
   luna-send -n 1 luna://com.webos.applicationManager/launch \
     '{"id":"com.novaos.launcher"}'
   ```

   Ответ с `errorCode`/`errorText` указывает стадию: `300` — приложение не
   найдено (пакет не зарегистрирован: перезагрузите ТВ), `301` — упал процесс
   (смотрите журнал и ручной запуск), `400` — отказ прав/ACG.
6. Журнал подмены Home, если включён режим «Подменять Home»:
   `/var/lib/novaos-home/boot.log`; откат — `/var/lib/novaos-home/restore.sh`.
